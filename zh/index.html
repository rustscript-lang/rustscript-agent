03 / Effect Sandbox

一次文件写入。
每个转换均有记录。

Tool Callwrite_file("race.txt", "first")
  1. 01
    先写入 Private View

    Managed Private View 已修改，对外可见的 Head 仍为 H0。

    candidate: race.txt = first
  2. 02
    冻结 Candidate

    停止 Writer，保存 Candidate Tree H1 与 Canonical Tool Result。

    prepare(H1, result)
  3. 03
    一次 Commit

    Expected-head 转换一并写入 Receipt、New Head、Result 与 Event。

    expected H0 → Head H1
  4. 04
    读回持久决策

    返回结果前，以 Durable Receipt 确认这次调用的结果。

    receipt fx_7a29
  5. 05
    恢复并保留历史

    Conflict 保留 Candidate 并报告不匹配。Restore 使用 Fresh Authority 创建 New Branch 与 New Run。

    conflict / new run

Managed File 与 Covered Plugin State 可以遵循 Checkpoint / Restore Contract。任意外部系统需要各自的 Reconciliation Contract；Runtime 不承诺将其反向恢复。

如果调用方没有收到最终回复，原 Attempt ID 可以取回 Durable Decision。Replay 返回已保存的 Tool Result，不会再次执行写入。

04 / Tool Graph

升级 Active Graph。
保留每个 Run Pin。

Activation 决定后续 Run 捕获什么，但不会替换 Live Run 正在使用的实现。

generation gGraph ARun α captured A
→
generation g + 1Graph BRun β captures B

Graph B 已通过 Validate 与 PermissionDiff。Run α 继续使用 Graph A；New Run β 捕获 Graph B。

generation g + 1Graph BRun β stays on B
→
generation g + 2Graph Anew Run γ captures A

Rollback 校验保留的 Graph A，并将它作为更晚的 Generation 激活。Run α 与 Run β 保持原 Pin；New Run γ 捕获 A。

已选择 Upgrade：Run α 保持 Graph A；New Run β 在 generation g + 1 捕获 Graph B。

05 / Pre-v1 边界

先讲清边界，
再讨论更大的能力。

01

Gateway Source Pinning

Gateway 通过文件选择的 Agent Source 目前尚未在 Durable Admission 时固定。Tool Graph Run Pin 覆盖已激活的 Tool Graph。

02

Restart Repair

Restart Repair 根据 Durable Record 对中断任务分类。Process-local Terminal Retry 不会跨 Restart 继续。

03

External Effects

Recovery Guarantee 仅适用于 Managed Adapter 已定义 Commit、Readback 或 Reconciliation Contract 的范围。
