03 / 作用沙箱

一次文件写入。
每个转换均有记录。

工具调用write_file("race.txt", "first")
  1. 01
    先写入私有视图

    受管私有视图已修改，对外可见的 Head 仍为 H0。

    候选：race.txt = first
  2. 02
    冻结候选内容

    停止写入方，保存候选树 H1 与规范化工具结果。

    准备(H1, 结果)
  3. 03
    只提交一次

    预期 Head 转换一并写入收据、新 Head、结果与事件。

    预期 H0 → Head H1
  4. 04
    读回持久决策

    返回结果前，以持久收据确认这次调用的结果。

    收据 fx_7a29
  5. 05
    恢复并保留历史

    冲突保留候选内容并报告不匹配。恢复操作使用新的授权创建新分支与新运行。

    冲突 / 新运行

受管文件与受覆盖的插件状态可以遵循检查点和恢复契约。任意外部系统需要各自的协调契约；运行时不承诺将其反向恢复。

如果调用方没有收到最终回复，原尝试 ID 可以取回持久决策。重放会返回已保存的工具结果，不会再次执行写入。

    日志

  • 02
    收据

    候选内容、Head 与工具结果共同绑定本次决策。

  • 03
    CAS 冲突

04 / 工具图谱

升级当前图谱。
保留每个运行的固定版本。

激活操作决定后续运行捕获什么，但不会替换运行中任务正在使用的实现。

第 g 代Graph A会话 A · Run α 保持 Graph A
→
第 g + 1 代Graph B会话 B · Run β 捕获 Graph B

激活操作隔离各个会话：会话 A 继续使用固定的 Graph A；会话 B 中的新运行捕获 Graph B。

第 g + 1 代Graph B会话 B · Run β 保持 Graph B
→
第 g + 2 代Graph A会话 B · 新 Run β′ 捕获 Graph A

回退操作校验保留的 Graph A，并将它作为更晚的代次激活。会话 A 与会话 B 中的现有运行保持原固定版本；会话 B 中的新 Run β′ 捕获 Graph A。

已选择升级：会话 A 中的 Run α 保持 Graph A；会话 B 中的新 Run β 在第 g + 1 代捕获 Graph B。

05 / 1.0 前的边界

先讲清边界，
再讨论更大的能力。

01

网关来源固定

网关通过文件选择的智能体来源目前尚未在持久准入时固定。工具图谱的运行固定版本覆盖已激活的工具图谱。

02

重启修复

重启修复根据持久记录对中断任务分类。仅存在于进程内的终态重试不会跨重启继续。

03

外部作用

恢复保证仅适用于受管适配器已定义提交、读回或协调契约的范围。

演进策略与工具。
保留授权、收据与运行固定版本。
