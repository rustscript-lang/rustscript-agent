01 / The gap

Isolation contains a process.
It does not account for an action.

OS policy, containers, and MicroVMs constrain execution. An agent runtime still has to bind meaning, authority, durable outcome, and tool version to every call.

03 / Effect Sandbox

One file write.
Every transition accounted for.

Tool callwrite_file("race.txt", "first")
  1. 01
    Write privately

    The managed private view changes while the published Head remains H0.

    candidate: race.txt = first
  2. 02
    Freeze the candidate

    Stop the writer and save candidate tree H1 with the canonical Tool Result.

    prepare(H1, result)
  3. 03
    Commit once

    An expected-head transition writes the Receipt, new Head, result, and Event together.

    expected H0 → Head H1
  4. 04
    Read back the decision

    The durable Receipt confirms the call outcome before the result returns.

    receipt fx_7a29
  5. 05
    Recover without erasing history

    A conflict retains the candidate and reports the mismatch. Restore creates a new branch and run with fresh authority.

    conflict / new run

Managed files and covered plugin state can follow checkpoint and restore contracts. Arbitrary external systems require their own reconciliation contracts; this runtime does not claim to reverse them.

If the caller misses the final reply, the original Attempt ID retrieves the durable decision. Replay returns the saved Tool Result without performing the write again.

04 / Tool Graph

Upgrade the active graph.
Keep every run pinned.

Activation changes what future runs capture. It never swaps the implementation under a live run.

Rollback validates retained Graph A and activates it as a later generation. Runs α and β keep their original pins; new Run γ captures A.

05 / Pre-v1 limits

Clear boundaries
before broad claims.

01

Gateway source pinning

Gateway file-selected agent source is not yet pinned at durable admission. Tool Graph run pins cover the activated tool graph.

02

Restart repair

Restart repair classifies interrupted work from durable records. A process-local terminal retry does not continue across restart.

03

External effects

Recovery guarantees apply only where a managed adapter defines the needed commit, readback, or reconciliation contract.

Evolve policy and tools.
Preserve authority, receipts, and run pins.

Start with the runtime model, then inspect the implementation and current limits.
